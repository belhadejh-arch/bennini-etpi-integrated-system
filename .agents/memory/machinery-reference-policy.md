---
name: Machinery reference policy
description: Product rules for the shared machinery register, historical operations, and driver costs.
---

The vehicles and machinery register is the only source of machinery names across rentals, fuel, spare parts, repairs, and driver costs. Relationships must survive renaming. Preserve older text-only operations and historical driver assignments rather than deleting them.

**Why:** The user explicitly repeated that all these workflows must use the same registered machinery and that replacing a driver must retain the previous driver's employment history.

**How to apply:** Reuse registered machinery choices in field entry and administrative review, and keep each field operation as the same attributable record when correcting its machinery link.

Automatic driver expense figures represent accrued salary, not proof that salary has been paid. Partial calendar months are prorated by their actual number of days.

**Why:** Automatic machine costs require an accrual convention, while no salary-payment workflow was requested.

**How to apply:** Keep accrued costs separate from any future payroll disbursement records so adding payment tracking does not count the same salary twice.
